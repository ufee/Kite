# Архитектура

[English](architecture.md) · **Русский**

Две части в одном процессе: ядро на Rust (`src-tauri/`) делает всю работу с сетью и диском, интерфейс на Vue 3 (`ui/`) работает в системном WebView2. Общаются через IPC Tauri: интерфейс вызывает команды, ядро шлёт события.

```
ui/ (Vue 3, TypeScript)          src-tauri/ (Rust, Tauri 2)
  components/  state/              ipc/  ── тонкие команды, ошибки кодами
  backend/ ── invoke / events ──►  ssh/  fs/  term/  transfer/  edit/
                                   store/  secrets/  log/
```

## Ядро: `src-tauri/src`

| Модуль | Роль |
|---|---|
| `ipc/` | Команды, которые вызывает интерфейс. Уводят работу с async-рантайма, переводят ошибки |
| `ssh/` | Подключения ([russh](https://crates.io/crates/russh)): одно на пару сервер–пользователь, несёт SFTP и терминалы. Ключи хостов по `~/.ssh/known_hosts`, порядок входа, запросы фразы и ключа хоста, проброс агента через фильтр |
| `fs/` | Файловые операции панелей: локальный диск и SFTP. В интерфейс уходят настоящие ошибки ОС, без догадок по битам прав |
| `term/` | Локальная оболочка на ConPTY и оболочки в SSH-каналах; у каждой вкладки одна упорядоченная очередь ввода |
| `transfer/` | Очередь передач: FIFO, 1–5 одновременно, свои подключения на пару сервер–пользователь, повторы, прямое копирование между серверами через rsync |
| `edit/` | Внешний редактор: временная копия, слежение за папкой, загрузка через очередь, проверка конфликта |
| `store/` | JSON-файлы в папке данных, атомарная запись; разбор импорта `servers.json` |
| `secrets/` | Пароли в системном хранилище |
| `log/` | Журнал отладки: кольцо из 1000 строк в памяти, уходит в интерфейс событиями |
| `portable.rs` | Включение портативного режима |
| `webview.rs` | Защита WebView: никаких браузерных клавиш, меню, масштаба и навигации |
| `error.rs` | Ошибки, идущие в интерфейс: код и факты, без формулировок |

Правила ядра:

- **Секреты не попадают в журнал.** Пароли и фразы живут в буферах `Zeroizing` и передаются только в SSH-слой; содержимое файлов пишется в журнал размером.
- **Без всплесков подключений.** Не больше трёх SSH-рукопожатий одновременно.
- **Переподключение** через 1, 3, 10 и 30 с, затем ошибка.
- **Долгое состояние держит ядро.** Очередь переживает перезагрузку интерфейса и сохраняется в `transfers.json`.
- **У интерфейса нет прав на файлы и диалоги.** `capabilities/default.json` разрешает только управление окном.

## Интерфейс: `ui/src`

| Папка | Роль |
|---|---|
| `components/` | Части окна: боковая панель, файловые панели, терминал, строка состояния, палитра, диалоги |
| `state/` | Реактивное состояние по областям: панели, серверы, очередь, терминалы, настройки, раскладка, сохранение сессии |
| `backend/` | Интерфейс `Backend` и две реализации: `tauri.ts` (ядро) и `mock/` (серверы и файлы в памяти) |
| `i18n/` | Русские строки в коде — это id сообщений; `en.ts` переводит их на английский |
| `platform/` | Управление окном, перехват браузерных клавиш WebView |

`npm run ui` запускает интерфейс в обычном браузере на мок-бэкенде: всё, кроме управления окном, работает без ядра и сервера.

## Примеры потоков данных

- **Открыть папку на сервере:** панель → `fs_list` → `ssh` берёт или открывает сессию → SFTP `readdir` → строки обратно.
- **Копирование:** `transfer_enqueue` → элемент очереди → события `transfer://state` (не чаще 10 раз в секунду) → `transfer://batch`, когда пачка завершилась.
- **Правка файла на сервере:** `edit_open` скачивает копию и запускает редактор → замечено сохранение → размер и дата сверяются с сервером → загрузка элементом очереди.
