# Разработка

[English](development.md) · **Русский**

## Требования

- Node.js 22.12+
- Стабильный Rust и [зависимости Tauri](https://tauri.app/start/prerequisites/) (только для десктопного приложения)
- Windows 10 или 11 с WebView2

## Команды

```bash
npm install
npm run ui      # только интерфейс, в браузере на http://localhost:5174, мок-бэкенд
npm run dev     # десктопное приложение с горячей перезагрузкой интерфейса
npm run check   # проверка типов интерфейса
npm run build   # релизная сборка
```

Проверки ядра, из `src-tauri/`:

```bash
cargo clippy --all-targets --locked -- -D warnings
cargo test --locked
```

## Соглашения

- Комментарии в коде — на английском.
- Строки интерфейса пишутся в коде по-русски и переводятся в `ui/src/i18n/en.ts`. Новой строке нужна запись там.
- Ошибки ядра несут код и значения; формулирует их интерфейс.
- Зависимости зафиксированы; везде `--locked`.
- Изменения — через pull request, см. [CONTRIBUTING.md](../CONTRIBUTING.md).

## CI

На каждый push в `main` и каждый pull request:

1. Поиск секретов.
2. Сборка интерфейса, генерация лицензий сторонних пакетов (`scripts/third-party.mjs`), Clippy и тесты на Windows.

## Релиз

1. Поставь версию в `src-tauri/tauri.conf.json` — единственное место, где она живёт.
2. Добавь в `CHANGELOG.md` секцию `## v<версия>` (конечный `.0` отбрасывается: `## v26.11`). Она станет заметками к релизу; без неё сборка падает.
3. Запушь тег `v<версия>`. Тег, не совпадающий с версией, валит сборку.
4. GitHub Actions собирает с чистого листа (без кэшей) и открывает черновик релиза:
   - `Kite-v<версия>-setup.exe` — установщик NSIS для текущего пользователя;
   - `Kite-v<версия>-portable.zip` — `Kite.exe` с `data\.kite-portable` (`scripts/package.ps1`);
   - `SHA256SUMS.txt`.
5. Проверь черновик и опубликуй.
