# Настройки и данные

[English](settings.md) · **Русский**

## Настройки

Открываются по **Ctrl ,** или шестерёнкой в заголовке окна.

| Раздел | Настройка | По умолчанию |
|---|---|---|
| Вид | Язык | Язык системы (русский или английский) |
| | Тема: тёмная, светлая, как в системе | Тёмная |
| | Окно: файлы, оба, терминал | Оба |
| | Шрифт терминала (12–16 px) | 13 |
| Подключения | Проверять ключи хостов | Вкл. Без проверки подмена сервера останется незамеченной |
| | Копировать между серверами напрямую | Выкл. См. [прямое копирование](user-guide.ru.md#прямое-копирование-между-серверами) |
| Серверы | Импорт и экспорт | |
| Передачи | Одновременно (1–5) | 3 |
| | Если имя занято: спрашивать, заменять, оставлять оба, пропускать | Спрашивать |
| | Не менять дату файлов при копировании | Вкл. |
| Редактор | Программа: системный, Notepad++, VS Code | Системный |
| | Сразу загружать правки на сервер | Вкл. |
| Терминал | Локальная оболочка: PowerShell 7, Windows PowerShell, командная строка | PowerShell 7 |
| | Копировать выделенное | Вкл. |
| | Сохранять историю терминала | Выкл. |

В разделе «Подключения» также видно, запущен ли агент OpenSSH и сколько в нём ключей.

## Где лежат данные

| Что | Где |
|---|---|
| Серверы, настройки, сессия, очередь передач, история терминала | `%APPDATA%\io.github.ufee.kite\` |
| Временные копии редактируемых файлов, кэш WebView | `%LOCALAPPDATA%\io.github.ufee.kite\` |
| Пароли | Диспетчер учётных данных Windows, по записи на сервер (для пользователя по умолчанию) |
| Ключи хостов | `~/.ssh/known_hosts`, общий с OpenSSH |
| Ключи | `~/.ssh` и агент OpenSSH; Kite их только читает |

Файлы в папке данных:

- `servers.json` — список серверов, без паролей
- `settings.json` — настройки и раскладка окна
- `session.json` — открытые панели, папки и терминалы
- `transfers.json` — очередь передач
- `terms/` — история терминала, только с включённым **Сохранять историю терминала**

Каждая запись атомарна. Файл, который больше не читается, откладывается в сторону (`settings.json` → `settings.bad`), и Kite запускается без него.

Парольные фразы ключей не сохраняются. Журнал отладки живёт только в памяти и на диск не пишется.

## Портативный режим

В портативном архиве — `Kite\Kite.exe` и `Kite\data\.kite-portable`. Пока этот файл-метка есть, всё, что пишет Kite (данные, копии для редактора, кэш WebView, положение окна), остаётся в `Kite\data`. Пароли и ключи хостов всё равно идут в диспетчер учётных данных и `~/.ssh/known_hosts`: они принадлежат пользователю, а не копии приложения.

Папка должна быть доступна на запись — не Program Files и не носитель только для чтения; иначе Kite скажет об этом и закроется. Удали `data\.kite-portable` — и копия будет вести себя как установленная.

## Переезд на другой ПК

1. **Импорт и экспорт → Экспорт** сохраняет `servers.json` (группы, серверы, пользователи, имена ключей; без паролей и ключей). Начальная папка, keepalive и режим ключа по умолчанию не экспортируются: импорт ставит домашнюю папку, 30 с и «Авто».
2. Ключи из `~/.ssh` перенеси отдельно.
3. На новом ПК: **Импорт**, затем подтверди ключ каждого хоста при первом подключении и, где нужно, введи пароли заново.
