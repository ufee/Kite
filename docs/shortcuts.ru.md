# Горячие клавиши

[English](shortcuts.md) · **Русский**

**F1** показывает этот список в приложении. Клавиши панелей работают, пока видны файлы, — не в виде «только терминал». Ещё: **Alt 1 / 2 / 3** работает как Ctrl, **Ctrl F5** обновляет, кнопка мыши «назад» — назад.

## Окно

| Клавиши | Действие |
|---|---|
| Ctrl K | Командная палитра: серверы, папки, команды |
| Ctrl P | Поиск серверов |
| Ctrl B | Свернуть или показать панель серверов |
| Ctrl 1 / 2 / 3 | Только файлы · оба · только терминал |
| Ctrl ` | Показать или скрыть терминал |
| Ctrl , | Настройки |

## Файловые панели

| Клавиши | Действие |
|---|---|
| Tab | Другая панель |
| Enter | Открыть |
| Backspace | Наверх |
| Alt ← | Назад |
| F3 | Просмотр |
| F4 | Редактировать во внешнем редакторе |
| F5 | Копировать в другую панель |
| F6 | Переместить в другую панель |
| F2 | Переименовать |
| F7 | Новая папка |
| Del | Удалить |
| Ctrl A | Выделить всё |
| Ctrl L | Править путь |
| Ctrl R | Обновить |
| Ctrl U | Поменять панели местами |
| Ctrl H | Показать или скрыть скрытые файлы |
| Ctrl + щелчок по серверу | Открыть сервер в другой панели |
| Shift + перетащить | Переместить вместо копирования |

## Палитра

| Клавиши | Действие |
|---|---|
| ↑ ↓ | Выбрать |
| Enter | Открыть в активной панели |
| Alt Enter | Открыть в другой панели |
| Esc | Закрыть |
