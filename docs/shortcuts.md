# Keyboard shortcuts

**English** · [Русский](shortcuts.ru.md)

**F1** shows this list in the app. Pane keys work while files are visible, not in terminal-only view. Also: **Alt 1 / 2 / 3** works like Ctrl, **Ctrl F5** refreshes, the mouse back button goes back.

## Window

| Keys | Action |
|---|---|
| Ctrl K | Command palette: servers, folders, commands |
| Ctrl P | Find servers |
| Ctrl B | Hide or show the server list |
| Ctrl 1 / 2 / 3 | Files only · both · terminal only |
| Ctrl ` | Show or hide the terminal |
| Ctrl , | Settings |

## File panes

| Keys | Action |
|---|---|
| Tab | Other pane |
| Enter | Open |
| Backspace | Up a folder |
| Alt ← | Back |
| F3 | View |
| F4 | Edit in an external editor |
| F5 | Copy to the other pane |
| F6 | Move to the other pane |
| F2 | Rename |
| F7 | New folder |
| Del | Delete |
| Ctrl A | Select all |
| Ctrl L | Edit the path |
| Ctrl R | Refresh |
| Ctrl U | Swap panes |
| Ctrl H | Show or hide hidden files |
| Ctrl + click a server | Open it in the other pane |
| Shift + drag | Move instead of copy |

## Palette

| Keys | Action |
|---|---|
| ↑ ↓ | Select |
| Enter | Open in the focused pane |
| Alt Enter | Open in the other pane |
| Esc | Close |
