# Руководство

[English](user-guide.md) · **Русский**

Kite — одно окно из трёх частей: список серверов слева, две файловые панели и терминал под ними. **Ctrl 1 / 2 / 3** переключает: только файлы, оба, только терминал.

## Серверы

**Добавить сервер** в боковой панели открывает карточку сервера:

| Поле | Что это |
|---|---|
| Имя | Короткое уникальное имя: латиница, цифры, дефис. Везде показывается вместо адреса (`code` в [servers.json](servers-json.ru.md)) |
| Группа | Группа в боковой панели |
| Описание | Что на сервере; по нему тоже ищется |
| Адрес, порт | IP или домен, порт по умолчанию 22 |
| Пользователи | Один или несколько логинов, один — по умолчанию. У каждого может быть свой ключ |
| Ключ по умолчанию | **Авто**: агент OpenSSH, затем `~/.ssh/id_ed25519`. **Файл ключа**: выбранный файл |
| Дополнительно | Начальная папка (по умолчанию домашняя), интервал keepalive |

**Проверить** проверяет адрес и вход по ключу до сохранения; пароль проверяется при сохранении.

### Вход

- **Ключ** (рекомендуется). Kite берёт ключи из агента OpenSSH и `~/.ssh`. Для ключа с паролем фраза спрашивается один раз; отметь **Добавить в агент OpenSSH** — и ssh, git и Kite больше не спросят. Фразы Kite не хранит.
- **Пароль.** Для пользователя по умолчанию; хранится в диспетчере учётных данных Windows, не в файлах Kite.
- **Добавить мой SSH-ключ.** Пароль вводится один раз: Kite входит, дописывает твой публичный ключ в `authorized_keys`, проверяет вход по ключу и забывает пароль.

Вход с двумя факторами (больше одного вопроса) не поддерживается.

### Ключи хостов

При первом подключении Kite показывает отпечаток сервера и команду для сверки. Принятые ключи пишутся в `~/.ssh/known_hosts` — тот же файл, что у OpenSSH. Если ключ сменился, Kite останавливается и показывает оба отпечатка: после переустановки сервера это нормально, иначе соединение могут перехватывать.

### Группы и поиск

Серверы сортируются по имени или по недавним, собираются в группы и фильтруются поиском (код, описание, адрес). Правый щелчок по серверу: войти другим пользователем, изменить, скопировать адрес, отключиться, удалить из списка. Удаление из списка ничего не меняет на сервере.

Серверов много — импортируй их из файла, см. [servers.json](servers-json.ru.md).

## Файловые панели

В каждой панели — **Этот ПК** или сервер. Щелчок по серверу открывает его в активной панели, **Ctrl + щелчок** — в другой. **Tab** переключает панели.

- **Ctrl L** — правка пути: `D:\папка` локально, `/путь` или `~` на сервере.
- В меню панели — видимые колонки (размер, изменён, права, владелец, группа) и скрытые файлы (**Ctrl H**).
- Правый щелчок по файлу: открыть, просмотр, редактировать, копировать или переместить в…, переименовать, права, терминал здесь, удалить.
- **Права и владелец…** — биты прав или восьмеричный код, можно рекурсивно. Чужие файлы меняет только root.
- Локально удаление идёт в корзину; на сервере удаление необратимо и спрашивает подтверждение.

## Копирование и перемещение

- **F5** копирует выделенное в другую панель, **F6** перемещает.
- Перетаскивание между панелями копирует, **Shift + перетащить** перемещает.
- Файлы можно перетащить в панель из Проводника.

Каждое копирование попадает в **очередь передач** (строка состояния → **Очередь**): прогресс, пауза, продолжение, отмена, повтор. По умолчанию одновременно идут 3 передачи (настройка **Одновременно**, 1–5). Потерянное соединение повторяется через 1, 3, 10 и 30 с; после перезапуска незавершённые передачи возвращаются на паузе.

Если имя занято, Kite спрашивает: заменить, оставить оба или пропустить, с галкой **Запомнить выбор**. Поведение по умолчанию — в настройках.

Kite пропускает то, что Windows не может сохранить (запрещённые имена, имена, отличающиеся только регистром), а также каналы, сокеты, устройства и ссылки — и пишет об этом в очереди.

### Прямое копирование между серверами

С включённым **Копировать между серверами напрямую** копирование с сервера на сервер запускает `rsync` на сервере-источнике, а тот входит на целевой с твоим проброшенным агентом: данные не идут через твой ПК. Нужно:

- твой ключ загружен в агент OpenSSH и принимается на целевом сервере;
- `rsync` на обоих серверах (один файл может пойти через `scp`);
- ключ хоста целевого сервера уже подтверждён в Kite;
- источник видит целевой сервер по сети.

Проброшенный агент только показывает ключи и подписывает, и только пока идёт копирование. В это время root на сервере-источнике может входить куда угодно с твоими ключами, поэтому включай это только для серверов, которым доверяешь. Если напрямую не получилось, Kite предложит скопировать через себя.

## Просмотр и редактирование

- **F3** — просмотр текстового файла до 10 МБ прямо в приложении.
- **F4** открывает файл в редакторе (системный, Notepad++ или VS Code, см. настройки). Файл с сервера скачивается во временную копию; каждое сохранение загружается обратно через очередь.
- Если файл на сервере изменился, пока ты его правил, Kite спросит, чья версия важнее.
- С выключенным **Сразу загружать правки на сервер** каждая загрузка спрашивает подтверждение.
- При закрытии Kite предупреждает о незагруженных правках.

## Терминал

В панели терминала — вкладки: локальная оболочка (PowerShell 7, Windows PowerShell или командная строка) или оболочка сервера. **Ctrl `** показывает и скрывает панель.

- **Терминал здесь** в панели открывает вкладку в этой папке.
- При разрыве соединения видна причина; **Enter** подключает снова.
- Выделение текста копирует его (настройка **Копировать выделенное**).
- **Сохранять историю терминала** — последние 1000 строк каждой вкладки, только на этом ПК.

## Командная палитра

**Ctrl K** ищет серверы, папки и команды. Вводи:

- часть кода, описания или адреса — найти сервер;
- `пользователь@код` — подключиться конкретным пользователем;
- `>` — только команды (вид, тема, поменять панели, скрытые файлы, новый сервер…).

**Enter** открывает в активной панели, **Alt Enter** — в другой.

## Строка состояния

- **Очередь** (пока есть передачи) и **Ошибок** — очередь передач.
- **Отладка** — журнал операций: что Kite делал и почему не получилось. В журнале нет паролей и содержимого файлов, но перед отправкой всё равно убери имена хостов и пользователей.
- Версия: щелчок копирует её для баг-репорта.

Раскладка окна, открытые папки и терминалы восстанавливаются при следующем запуске.
