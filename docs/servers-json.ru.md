# servers.json

[English](servers-json.md) · **Русский**

Файл для переноса списка серверов между машинами или сборки его из заметок. **Настройки → Импорт и экспорт** (или `>` в палитре).

## Формат

```json
{
  "version": 1,
  "groups": [
    { "name": "Production", "servers": [
      { "code": "web1", "description": "Главный веб-сервер", "host": "203.0.113.17", "port": 22,
        "users": [
          { "name": "root", "default": true },
          { "name": "deploy", "key": "deploy_ed25519" }
        ] }
    ] }
  ]
}
```

Подходит и плоский список: `{ "servers": [ ... ] }`, где у сервера может быть своё поле `"group"`.

| Поле | Обязательно | Правило |
|---|---|---|
| `version` | нет | `1`, если указано |
| `code` | да | Уникальный; латиница, цифры, дефис; начинается с буквы или цифры |
| `host` | да | IP или домен, без пробелов |
| `port` | нет | 1–65535, по умолчанию 22 |
| `description` | нет | Что на сервере |
| `users` | нет | По умолчанию один пользователь `root` |
| `users[].name` | да | Уникален в пределах сервера |
| `users[].key` | нет | Имя файла из `~/.ssh`, без пути. Не указан или `auto` — агент, затем `id_ed25519` |
| `users[].default` | нет | Логин по умолчанию; иначе первый пользователь |

Пароли, парольные фразы и приватные ключи в этот файл не попадают. Максимальный размер — 2 МБ.

## Импорт

Перетащи файл, выбери его или вставь кнопкой **Из буфера**; **Пример** подставляет образец. Kite сопоставляет серверы по `code` и до применения показывает изменения: новые, изменённые (адрес, порт, описание, группа, пользователи), без изменений. **Удалить серверы, которых нет в файле** дополнительно убирает серверы, которых нет в файле; по умолчанию выключено.

## Экспорт

Выбери группы и, нужно ли включать **Пользователи и имена ключей**, затем **Сохранить** в файл или **Копировать** JSON. Результат в том же формате и импортируется обратно как есть.

## Сборка с помощью ИИ-агента

**Копировать для агента** кладёт в буфер готовое задание с этим форматом. Вставь его в любой ассистент вместе с заметками о серверах и импортируй ответ.
